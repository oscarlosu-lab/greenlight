Frequently Asked Questions

How is Greenlight Windows Edition different from upstream Greenlight?

This fork focuses exclusively on Windows PCs and ships ~100 upgrades over v2.4.2: 1440p streaming, HEVC/AV1 decoding, Clarity Boost, LAN host-first ICE, DPAPI encrypted tokens, multi-account & multi-instance support, 4-player co-op, 13 languages, Electron 45, and a draggable real-time FPS HUD.

Does it work on Windows handhelds like ASUS ROG Ally, Lenovo Legion Go, or MSI Claw?

Yes. It runs natively on Windows 10 and Windows 11 with built-in gamepad UI navigation, vibration support, custom button remapping, and Clarity Boost.

Does the FPS counter show real live FPS?

Yes. When enabled in Settings, Greenlight polls WebRTC inbound-rtp video statistics every second and displays the actual decoded framesPerSecond (for example 30FPS, 60FPS, or 120FPS) in a draggable overlay.

Is it open source and free?

Yes, Greenlight is 100% free and MIT-licensed. You can inspect the full source code, tests, and CI workflows on GitHub.
